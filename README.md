# AI-Gedragsconfigurator — Versie 1

**Publieke waarden → Ontwerpkeuzes → AI-gedrag → Zichtbare consequenties**

Een ontwerpdemonstratie van een fundamenteel principe: menselijke regie over AI ontstaat niet alleen doordat we zeggen dat de mens verantwoordelijk blijft, maar doordat mensen daadwerkelijk keuzes kunnen maken die het gedrag van AI veranderen — én het effect daarvan kunnen zien.

## V1

Drie pedagogische presets demonstreren hetzelfde onderliggende principe:

- Socratische Tutor
- Examenvoorbereider
- Kritische Sparringpartner

De vergelijkende preview gebruikt steeds dezelfde vraag. Alleen de gedragsconfiguratie verandert. De preview is gesimuleerd en is dus geen voorspelling van exacte uitvoer van een specifiek taalmodel.

## Ontwerpgrens

Betrouwbaarheid is geen vrij instelbare gedragsvoorkeur. De gegenereerde instructie bevat daarom vaste uitgangspunten voor feitelijke betrouwbaarheid en het zichtbaar maken van relevante onzekerheid.

V1 is bewust een demonstrator, geen compleet product of LMS-functionaliteit.
